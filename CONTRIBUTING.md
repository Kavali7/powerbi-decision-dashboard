# Contribuer à ce dépôt

Ce dépôt est un projet de démonstration à usage personnel et professionnel.

## Règles

- **Données** : toute donnée ajoutée doit rester **fictive et synthétique**. Ne jamais ajouter de données réelles.
- **Cas clients** : ne jamais ajouter de faux cas clients, faux témoignages ou faux résultats.
- **Nommage** : respecter la convention de nommage existante (colonnes en anglais, contenu en français).
- **Structure** : conserver l'arborescence définie dans le README.
- **Qualité** : chaque ajout doit maintenir le niveau de lisibilité et de sobriété du projet.

## Structure du dépôt

```
data/raw/          → données sources dimensionnelles et factuelles
data/processed/    → dataset consolidé prêt pour Power BI
data/dictionary/   → dictionnaire de données
scripts/           → scripts Python de génération et préparation
docs/              → documentation métier et technique
dashboard/powerbi/ → fichier Power BI (ou placeholder)
assets/            → visuels, graphiques, diagrammes, PDFs
notebooks/         → notebooks Jupyter de démonstration
```
