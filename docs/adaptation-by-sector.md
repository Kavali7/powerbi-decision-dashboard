# Adaptation par secteur

Ce modèle de tableau de bord décisionnel peut être adapté à différents secteurs. Voici les principales transpositions.

---

## PME commerciale

| Élément du modèle | Adaptation |
|---|---|
| Zones | Régions commerciales, agences |
| Composantes | Lignes de produits, canaux de vente |
| Activités planifiées | Objectifs de vente |
| Activités réalisées | Ventes effectives |
| Bénéficiaires | Clients servis |
| Budget | Budget commercial par zone |
| Alertes | Zones sous-performantes, produits en déclin |

## Principes d'adaptation

Quel que soit le secteur, l'adaptation repose sur les mêmes principes :

1. **Identifier les dimensions** : qui pilote quoi, où, quand.
2. **Définir les mesures** : planifié vs réalisé, cible vs atteint.
3. **Choisir les seuils d'alerte** : adapter les % aux normes du secteur.
4. **Garder la sobriété** : peu d'indicateurs, bien choisis.
5. **Prioriser la décision** : chaque visuel doit répondre à une question métier.
